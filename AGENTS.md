\# BudgetLocal



Application Windows WPF en C# / .NET 10.



\## Architecture

\- BudgetLocal.Desktop : Interface WPF.

\- BudgetLocal.Core : Services métier et SQLite.

\- BudgetLocal.Tests : Tests automatisés.

\- Les projets actifs sont Desktop, Core et Tests; aucune interface Web n'est maintenue.



\## Données

\- SQLite dans %LocalAppData%\\BudgetLocal.

\- Ne jamais supprimer les données ou sauvegardes sans accord.



\## Consignes

\- Inspecter uniquement les fichiers pertinents.

\- Réutiliser les services existants.

\- Éviter les refactorisations sans rapport avec la tâche.

\- Préférer les modifications ciblées.

\- Compiler après les changements importants.

\- Ne pas déclarer un test réussi sans l'avoir exécuté.

\- Répondre brièvement en français.
